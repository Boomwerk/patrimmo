# 🏠 Patrimmo - En Cours De developpement

> Application SaaS de gestion immobilière développée avec Symfony et React.

## 📖 À propos du projet

Patrimmo est une application web permettant aux propriétaires et gestionnaires immobiliers de centraliser la gestion de leurs biens, locataires et documents administratifs.

L'objectif du projet est de proposer une solution simple et moderne pour faciliter le suivi d'un parc immobilier : gestion des logements, suivi des locations, génération de documents et suivi des paiements.

Ce projet a été réalisé dans une approche **Full-Stack moderne**, avec une séparation complète entre une API Symfony et une application frontend React.

---

## 🎯 Objectifs du projet

À travers Patrimmo, j'ai souhaité mettre en pratique :

- La conception d'une application SaaS complète
- La création d'une API REST sécurisée
- Une architecture frontend maintenable avec React
- La gestion d'une authentification JWT
- La mise en place d'une architecture basée sur les fonctionnalités (feature-based)
- L'utilisation de Docker pour simplifier l'environnement de développement

---

# ✨ Fonctionnalités

## 🔐 Authentification

- Inscription et connexion utilisateur
- Authentification avec JWT
- Protection des routes privées
- Gestion du profil utilisateur
- Modification du mot de passe

## 🏢 Gestion des biens immobiliers

- Création et modification de biens
- Gestion des informations d'un logement :
  - Adresse
  - Type de bien
  - Surface
  - Nombre de pièces
  - Montant du loyer

## 👤 Gestion des locataires

- Ajout de locataires
- Association d'un locataire à un logement
- Gestion des informations personnelles

## 📄 Gestion documentaire

- Centralisation des documents liés aux locations
- Préparation de la gestion des documents administratifs

## 💰 Suivi des loyers

- Suivi des paiements
- Gestion des loyers impayés
- Préparation d'un système d'alertes automatiques

## 📊 Tableau de bord

- Vue globale de l'activité immobilière
- Visualisation des informations importantes
- Accès rapide aux différentes fonctionnalités
